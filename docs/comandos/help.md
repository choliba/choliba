# `choliba help`

> Mostra a ajuda da raiz ou de um comando, a mesma de --help, e termina com o endereço da página do comando.

## Uso

```sh
choliba help [COMANDO...]
```

## Exemplos

Os comandos da raiz:

```sh
choliba --help
```

A ajuda de um comando:

```sh
choliba help run tests
```

## Detalhes

`choliba --help`, `choliba -h` e `choliba COMANDO --help` mostram o mesmo. A ajuda de cada comando termina com o endereço da página dele nesta referência.
